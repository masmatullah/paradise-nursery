# Paradise Nursery Shopping Application

## Project Description
Paradise Nursery is an online plant shopping application built using React.js and Redux Toolkit.

Users can browse different categories of houseplants, view product details, add plants to their shopping cart, manage quantities, and calculate the total cost.

## Features
- Attractive landing page
- Three plant categories
- Minimum six plants per category
- Add to Cart functionality
- Dynamic shopping cart counter
- Increase and decrease product quantities
- Remove products from cart
- Automatic price calculation
- Responsive design

## Technologies Used
- React.js
- Redux Toolkit
- React Redux
- React Router DOM
- JavaScript
- CSS
